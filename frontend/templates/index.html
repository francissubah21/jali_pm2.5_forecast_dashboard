Chronological holdout

Training655 days
Testing72 days
Train end19 Dec 2023
Test end29 Feb 2024

No random shuffling. ML rolling features are shifted by one day to prevent target leakage.

Random Forest and XGBoost feature importance

Model-specific predictive importance, not causal importance

Lag 1 dominates both tree models because the most recent PM2.5 value carries strong short-term temporal information. Importance should not be interpreted as proof that a feature causes PM2.5 changes.
